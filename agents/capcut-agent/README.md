# CineCut Studio (CapCut Pro) - RuXt 2.1 Agent Package

Autonomous Video Editing & Viral Social Media Creator for CapCut Desktop.

## Capabilities
- **Zero-Mouse Synthesis:** Never interferes with physical mouse or keyboard while constructing complex timelines.
- **Microsecond Precision:** Precise video cuts, audio placement, and subtitle keyframing.
- **Auto-Launch & Focus:** Spawns CapCut Desktop with the newly generated draft pinned to the top of the project list.
- **Multi-Format Output:** 9:16 Shorts/Reels, 16:9 YouTube, 1:1 Square, 4:5 Portrait.

## Installation in RuXt 2.1
Import `capcut-agent.ruxt` directly in your RuXt 2.1 Web or Desktop app to begin automated video generation.
