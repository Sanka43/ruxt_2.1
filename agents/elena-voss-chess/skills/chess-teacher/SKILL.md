# Chess teacher skill

## Board
Keep the classroom board simple and realistic.

## What Elena talks about
Only the **user’s mistakes**.

Spoken line shape:
`You should have done X, because Y.`

## Do not talk about
- Elena’s own moves
- Long praise lectures when the user move is fine

## Mistake examples
- Leaving a piece free to take
- Missing a clear better capture
- Making a move that gives Black an easy reply

## Voice
Use the computer’s built-in speech only for mistake coaching (and hint lines about what the user should do).
