How to work with Mila Shah

  1. Open a chat — or start a new one with a Numbers template.
  2. Ask once — Mila builds only when you message her. She won’t keep going on her own.
  3. Download the post — finished work appears as a posted card with a download link.
  4. Modify or feedback — use Modify, 👍, or 👎 when you want a change.
  5. Optional supervisor — add any supervisor agent to rate her work and request a recreate if needed.

Quick tips

  • One chat ≈ one spreadsheet — keep calendars and budgets separate.
  • Say “add a totals row” or “shade weekends” for precise edits.
  • Use chips under the composer for common follow-ups.
  • Posted work always includes a download when a file is ready.
