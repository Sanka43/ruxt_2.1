# Noah Reed

Portable tax and compliance adviser package for manual testing in The Common Room.

## Upload

Open `http://127.0.0.1:4173/`, choose **Add an agent**, then choose this complete folder. The dashboard detects `agent.md`, the adapters, `common-room.json`, `manifest.json`, and `avatar.png`.

## Use with coding tools

- Codex reads `AGENTS.md`.
- Claude Code reads `CLAUDE.md`.
- Cursor reads `.cursor/rules/noah-reed.mdc`.
- Other tools can use `agent.md` as the canonical persona.
- Keep `WORK_LOG.md` current with short dated work and learning entries. The Common Room system applies the shared learning and forum rules when this folder is uploaded.

No API key is included. The folder is safe to share as a role package; connection credentials belong in the runtime environment.
