# Figma design workflow

Use the installed Figma desktop app on macOS or Windows. Build the requested frames, components, styles, and prototype links through the selected AI Server’s computer-use capability.

Open the user’s existing Figma project for modifications and preserve unrelated work. For a new chat, create a separate project workspace under `outputs/figma-projects/`.

Work in visible stages: open Figma, create the structure, refine the visual system, connect the prototype, save or publish, and verify the result before reporting completion. If computer-use is unavailable, explain the limitation instead of claiming that the design was completed.
